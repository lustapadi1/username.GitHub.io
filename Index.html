📖 Full Curriculum (9 Modules)

Module 1: Network Fundamentals (40h)

▼

Topics: OSI vs TCP/IP models, network topologies, protocol analysis (HTTP/DNS/DHCP), media types.

Protocol | Port | Function
HTTP     | 80   | Web traffic
HTTPS    | 443  | Secure web
DNS      | 53   | Name resolution
DHCP     | 67/68| IP assignment

Module 2: Network Infrastructure (60h)

▼

Topics: Switches, routers, wireless (Wi-Fi 6), cabling standards (Cat6/6A/8, fiber).

CableSpeedMax Distance
Cat 61 Gbps100m
Cat 6A10 Gbps100m
Single-mode fiber100 Gbps+Up to 100km

Module 3: IP Addressing & Subnetting (50h)

▼

Topics: IPv4 classes, subnetting, VLSM, CIDR, IPv6 addressing, NAT/PAT.

Subnet formula: 2^n subnets, 2^h - 2 hosts
Example: 192.168.1.0/26 → 64 addresses, 62 usable hosts
IPv6: 2001:db8::/32

Module 4: Routing & Switching (80h)

▼

Topics: VLANs, STP, EtherChannel, static/dynamic routing (OSPF, EIGRP, BGP).

! Cisco VLAN config
Switch(config)# vlan 10
Switch(config-vlan)# name SALES
Switch(config-if)# switchport mode trunk

Module 5: Network Services (60h)

▼

Topics: DHCP, DNS, Active Directory/LDAP, NTP, Syslog.

# Windows DHCP Scope
Add-DhcpServerv4Scope -StartRange 192.168.1.100 -EndRange 192.168.1.200

Module 6: Network Security (70h)

▼

Topics: ACLs, firewalls (Palo Alto, FortiGate), VPNs (IPsec, SSL), IDS/IPS, 802.1X.

# Suricata rule example
alert tcp $HOME_NET any -> $EXTERNAL_NET 443 (msg:"TLS Anomaly";)

Module 7: Network Management (60h)

▼

Topics: SNMP (Zabbix, PRTG), NetFlow, packet analysis (Wireshark), Ansible automation.

▼

Topics: VMware NSX, AWS VPC, Azure Virtual Network, Terraform for network as code.
